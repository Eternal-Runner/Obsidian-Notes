# Obsidian-Notes

本仓库的每个笔记文件夹都是一个 Obsidian 仓库，直接用 Obsidian 打开即可。

Obsidian 是一款免费的笔记软件。请前往官网下载：https://obsidian.md

## Features

- 尽可能对于每条知识都进行构造性的解释，即从现有知识出发去建立对新知识的认知，避免没有根源、需要强记的知识（如凭空的方法、莫名的特例、奇怪的反直觉），方便读者建立知识体系。
- 笔记内容均基于**课件和课本**整理。同时在编写过程中大量查阅互联网资料，对于疑点内容，尤其是术语、翻译、概念分类等进行核实，力求准确。然而笔者经历有限，无法在每一处标注参考资料，大部分参考资料源于：
  - 英文维基百科：https://en.wikipedia.org/ - 英文术语、国际学界观点等
  - 中文维基百科：https://zh.wikipedia.org/ - 中文术语、中国学界观点等
  - 百度百科：https://baike.baidu.com/ - 中文术语，中国学界观点等
- 笔记对于知识进行了一定深度的解读和拓展，包括原理、体系、对比、联系、技巧等，读者可以选择性地阅读。
